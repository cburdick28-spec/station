# Railgrid · Corvane Central

Live 3D train station ops game. Single `index.html`, Three.js from a CDN, no build step.

- Click a highlighted platform to route each arriving train (Manual mode), or switch to Auto.
- Hold trains for more passengers, dispatch early, send a crew when signals fail.
- Shift runs 07:52 → 12:00. Keep the mood up, score points, get a grade.
- Keys: N night · C cinematic · 1/2/3 speed.
